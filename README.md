## Running the Projects Locally

### Vanilla Projects (1, 2, and 3)

No package installation or build step is required.

1. Open the relevant folder (`1-calculator`, `2-todo-list`, or `3-form-validation`).
2. Open its `index.html` in your browser.
3. Alternatively, open the repository's root `index.html` to browse the projects from a unified hub.

### React Component Suite (`react-app`)

The React project uses React and Vite. Install Node.js (v18 or newer), then run:

```bash
cd react-app
npm install
npm run dev
```

Open the local address Vite prints, usually `http://localhost:5173/`.

## GitHub Pages Deployment

The portfolio is deployed using GitHub Actions. The workflow builds the React/Vite application and publishes it alongside the three vanilla JavaScript projects.

- The vanilla assignments are available in their respective repository subdirectories.
- The React app is built with Vite and published under `/react-app/`.
- Deployment is triggered when changes are pushed to the `main` branch.
