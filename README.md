## Overview

This repository contains a curated suite of frontend web applications and components showcasing DOM manipulation, state machines, regex form verification, and modular React 18 architectures.

| # | Project / Module | Technology | Directory |
|---|------------------|------------|-----------|
| 1 | Aesthetic Keypad Calculator | Functions, Keypad State Machine, Event Delegation | `1-calculator` |
| 2 | Daily Flow Task Tracker | DOM Manipulation, LocalStorage, Custom State | `2-todo-list` |
| 3 | Studio Registration & Validator | Real-time Regex, Password Entropy Engine | `3-form-validation` |
| 4 | Creative Profile Showcase | React Props, Dynamic Avatar Fallbacks | `react-app` (Tab 1) |
| 5 | Controlled Studio Form | React Two-way Binding, JSON State Inspector | `react-app` (Tab 2) |
| 6 | Gentle Mood Counter | React `useState` Hook, Step Adjuster | `react-app` (Tab 3) |

## Running the Projects Locally

### Modules 1, 2, and 3 (Vanilla JS & Modern CSS)
No build steps or installations required.
1. Navigate into any folder (`1-calculator`, `2-todo-list`, or `3-form-validation`).
2. Open `index.html` directly in your favorite browser, or launch the root `index.html` to browse all assignments from a single hub.

---

### React Component Suite (`react-app`)
Powered by Vite and React 18.

1. Ensure **Node.js** (v18 or higher) is installed.
2. In your terminal:
   ```bash
   cd react-app
   npm install
   npm run dev
   ```
3. Open `http://localhost:5173/` in your browser.

## Aesthetic Design Architecture
This project implements an organic **Minimalist Cream & Matcha Sage** design language:
- **Base Surfaces:** Warm cream `#faf8f2` and soft botanical matcha green `#6b8e6b`
- **Glassmorphism:** Multi-layered translucent panels (`backdrop-filter: blur(20px)`) with crisp soft-white borders.
- **Typography:** `Outfit` and `Plus Jakarta Sans` for clean, peaceful legibility.
