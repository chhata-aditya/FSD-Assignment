## Running the Projects Locally

### Vanilla projects (1, 2, and 3)

No package installation or build step is required.

1. Open the relevant folder (`1-calculator`, `2-todo-list`, or `3-form-validation`).
2. Open its `index.html` in a browser.
3. Or open the repository's root `index.html` to use the project hub.

### React component suite (`react-app`)

The React project uses React and Vite. Install Node.js (v18 or newer), then run:

```bash
cd react-app
npm install
npm run dev
```

Open the local address Vite prints (usually `http://localhost:5173/`).

## GitHub Pages Setup

To publish the three vanilla projects from this repository:

1. On GitHub, open **FSD-Assignment → Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **`main`** and folder **`/(root)`**, then click **Save**.
4. Wait for the Pages deployment to complete. The links above use the repository's expected Pages address.

The React/Vite app is listed as a local project; it needs a separate Vite build/deployment configuration to publish it on Pages.
